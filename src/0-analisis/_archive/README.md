# 0-Análisis: SpecKit e IREB — Estudio Comparativo

## Propósito de esta carpeta

Este directorio contiene el análisis previo al diseño metodológico del TFG. Aquí se documenta la investigación sobre el flujo de trabajo de **SpecKit** (fuentes oficiales, actualizadas a junio 2026), su comparación con el marco **IREB CPRE Foundation Level**, y las decisiones de diseño que justifican la metodología adoptada en `src/metodologia.md`.
