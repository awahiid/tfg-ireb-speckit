# Comparativa IREB vs SpecKit: Alineación de procesos de especificación de requisitos

**Trabajo de Fin de Grado (TFG)** | Grado en Ingeniería Informática del Software

## Objetivo General

Este proyecto realiza una comparativa integral entre el **marco IREB (International Requirements Engineering Board) Foundation Level** y **SpecKit** (un pipeline de agentes de GitHub especializado en especificación), con el propósito de validar y mapear la alineación entre:

1. El proceso de definición de requisitos establecido por IREB
2. La especificación y arquitectura de agentes en SpecKit

## Objetivo Específico

Identificar y formalizar las brechas metodológicas entre IREB y SpecKit, de modo que los requisitos generados con SpecKit no dependan únicamente de la libertad de configuración del usuario, sino que incorporen de manera verificable los principios, actividades, criterios de calidad, trazabilidad y mecanismos de gestión de requisitos definidos por IREB.

## Descripción del Trabajo

### Enfoque y Metodología

El análisis se fundamenta en:

- **IREB Foundation Level Handbook**: Estudio exhaustivo del ciclo de vida, técnicas y buenas prácticas en Requirements Engineering
- **SpecKit**: Análisis de su arquitectura como pipeline de agentes y validación de que sus especificaciones (ficheros de configuración) están alineados con el proceso IREB

### Componentes Principales

1. **Análisis Teórico (IREB)**
   - Procesos de elicitación, análisis, validación y gestión de requisitos
   - Principios fundamentales de RE
   - Ciclo de vida completo de requisitos
   - Técnicas y herramientas

2. **Análisis Técnico (SpecKit)**
   - Arquitectura del pipeline de agentes
   - Especificaciones de entrada/salida
   - Validación de alineación con procesos IREB

3. **Comparativa y Resultados**
   - Mapeo directo entre IREB y SpecKit
   - Identificación de brechas
   - Recomendaciones de alineación
