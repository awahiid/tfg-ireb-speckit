### ID

REQ-N8N-31253

### Nombre

Enriquecer la respuesta de la API de credenciales para flujos de trabajo

### Tipo

Funcional

### Descripción formal

El sistema deberá modificar la respuesta del endpoint `GET /credentials/for-workflow` para que, por cada credencial devuelta, incluya los siguientes campos adicionales, alineando su estructura con el tipo esperado por el frontend (`ICredentialsResponse`):

1.  **`createdAt` y `updatedAt`**: Las fechas de creación y última actualización de la entidad de la credencial.
2.  **`homeProject`**: El proyecto de origen de la credencial. Debe ser `null` para credenciales globales.
3.  **`sharedWithProjects`**: Una lista de otros proyectos con los que la credencial está compartida.
4.  **`currentUserHasAccess`**: Un valor booleano que siempre será `true`, ya que la lista de resultados representa credenciales a las que el usuario actual tiene acceso.

### Fuente

Pull Request #31253 (https://github.com/n8n-io/n8n/pull/31253)

### Rationale

La respuesta de la API no coincidía con la estructura de datos (`type`) que el frontend esperaba, lo que provocaba errores de `undefined` en tiempo de ejecución al acceder a campos que no estaban presentes. Este cambio enriquece la respuesta para que sea estructuralmente compatible, eliminando la discrepancia y asegurando que el frontend reciba todos los datos que necesita para renderizar la información de propiedad y compartición de credenciales.

### Prioridad

Alta

### Verificación

1.  **Credencial estándar**:
    a. Realizar una petición a la API `GET /credentials/for-workflow` para un flujo de trabajo que tenga acceso a una credencial no global.
    b. Verificar que la respuesta JSON para esa credencial contiene los campos `createdAt`, `updatedAt`, `homeProject` (no nulo), `sharedWithProjects` y `currentUserHasAccess: true`.

2.  **Credencial global**:
    a. Realizar una petición para un flujo de trabajo con acceso a una credencial global.
    b. Verificar que el campo `homeProject` en la respuesta es `null`.

3.  **Sin credenciales**:
    a. Realizar una petición para un flujo de trabajo sin credenciales asociadas.
    b. Verificar que la respuesta es un array vacío y que el sistema no ejecuta consultas adicionales para obtener relaciones de compartición.
